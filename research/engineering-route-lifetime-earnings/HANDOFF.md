# 引き継ぎ書：工学系4ルートの生涯年収比較

更新：2026-11-13

## 1. 依頼内容

日本の男子中学生が工学系に進む場合の4ルートについて、生涯年収（65歳まで）を公的統計で比べること。

- A：工業高校卒（18歳で就職）
- B：高専卒（20歳で就職）
- C：高専から大学3年次に編入して卒業（22歳で就職）
- D：普通科高校から理系大学に進学して卒業（22歳で就職）

条件は、男性・正社員・全国平均・工学系・2026年の賃金水準です。あわせて次の4点も求められています。

- **平均と中央値の区別**：平均値を中央値として扱わない。
- **選抜効果の区別**：「同じ学力の人が選んだ場合」と「実際に進んだ人の平均」を分けて考える。
- **3つのケース**：典型的な卒業生／従業員1000人以上の大企業／IT業界。
- **感度分析**：賃金の伸び、転職の有無、大企業で65歳まで、役職定年・再雇用。

## 3. 結論

退職金込みの生涯賃金（ケース1：典型的な卒業生）は次のとおりです。

| 順位 | 進路 | 生涯賃金 |
|---|---|---|
| 1 | C 高専→大学編入 | 3.55億円 |
| 2 | B 高専 | 3.38億円 |
| 3 | D 普通科→理系大学 | 3.34億円 |
| 4 | A 工業高校 | 2.80億円 |

- **A（工業高校）が最も低い**：どの条件で試算しても最下位で、結論として頑健です。
- **B（高専）とD（普通科→理系大）はほぼ同等**：差は推計誤差の範囲内です。将来の所得を割り引いて比べると、Bの方が有利になります（2％割引でB 1.92億、D 1.81億）。
- **C（高専→編入）が1位なのは仮定による**：「編入先は国立大中心なので、平均的な工学部卒より6.5％高く稼ぐ」と置いた結果です。編入そのものが賃金を押し上げることを示すデータはありません。
- **CとDが同じ国立大を出た場合**：このモデルでは生涯賃金は同額です。違いは学費だけで、Cがわずかに安く済みます。
- **依頼者への最終回答**：平均的な卒業生が高い生涯年収を再現性高く得られるのは、高専（B）の系統です。

## 4. 推計の方法

| 進路 | 推計の方法 | 主なデータ |
|---|---|---|
| A | 高卒男性の正社員の賃金カーブに、工業科卒の業界構成（製造業54％など）で補正をかける | 令和7年賃金構造基本統計調査、令和7年度学校基本調査 |
| B | 2つの方法の平均（下記）。推計の幅は3.13〜3.28億円（退職金を除く） | 賃金構造基本統計調査、令和4年就業構造基本調査 |
| C | Dの賃金カーブ × 1.065（国立大を出たことによる上乗せの仮定） | 濱中（2017）の国公立大卒と私大卒の収入比 |
| D | 大卒男性の正社員の賃金カーブに、工学部卒の業界構成で補正をかける（補正はほぼ±1％にとどまる） | 賃金構造基本統計調査、学校基本調査 |

**Bの2つの方法**

賃金構造基本統計調査には「高専・短大」をまとめた区分しかなく、高専卒だけの賃金表がありません。就業構造基本調査は高専と短大を分けているので、これを使って補正しています。

- 方法1：賃金構造の「高専・短大」の賃金から、短大卒の分を補正して取り除く。
- 方法2：賃金構造の「大卒」の賃金に、就業構造で見た「高専卒÷大卒」の年収比を掛ける。

**その他の前提**

- 60〜64歳は再雇用を含めるため、正社員に限らないフルタイム労働者（一般労働者計）の賃金を使っています。
- 2026年の水準に直すため、月給を+3.0％、賞与を+6.2％、初任給を+3.5％上げています。
- 中央値は推計値です。年齢ごとの「中央値÷平均」の比（就業構造基本調査）を平均の賃金カーブに掛けて出しています。
- 退職金は令和5年就労条件総合調査が基準です。Bの1,800万円と、期待値計算で掛けている0.7倍は仮定です。
- 税金と社会保険料は、2026年の制度で単身・扶養なしとして簡易に計算しています。
- 前提の一覧は `README.md` の付録に、各数値は `model/model.py` の `ASSUME` と `COSTS` にまとめてあります。

## 6. 注意点と限界

- **Cの推計の確からしさが最も低い**：学部卒で就職する編入生の賃金を直接示す統計がありません。実際には編入生の多くは大学院に進みます（参考値：編入して修士を出た場合は約4.1億円）。
- **IT業界のケースではAを過大評価している可能性**：情報通信業で働く高卒には通信大手の現場職が多く含まれるためです。学歴差を一般的な水準で当てはめた別の推計では2.94億円です。
- **大学の難易度による倍率は仮定**：旧帝大1.15倍、地方国公立1.05倍などは、報告書内でも「仮定」と明記しています。大学の選抜度そのものの効果は、学力を考慮すると小さいとする研究があります（Nakamuro & Inui 2013）。
- **横断面データであること**：2025年時点の各年齢の人の賃金を、1人の生涯の賃金とみなしています。
- **年齢ごとの中央値の合計は、生涯年収の中央値と同じではない**：報告書にもその旨を書いています。
- **公的統計の欠落**：工業科卒や工学部卒に限った賃金統計はありません。また賃金構造基本統計調査は官公庁を対象に含みません。
